# Fractal Reader

Chrome-расширение для глубокого анализа текста с помощью Claude AI.

![Fractal Reader](https://img.shields.io/badge/Chrome-Extension-blue) ![Claude AI](https://img.shields.io/badge/Claude-AI-purple)

## Возможности

Выделите текст на любой веб-странице и получите:

- **Диалектика** — тезис, антитезис и синтез выделенного фрагмента
- **Отсылки** — литературные и философские референсы
- **Связи** — связь с другими концепциями и идеями
- **Вопросы** — провокационные вопросы для размышления

## Установка

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/aglitskaya07/fractal-reader.git
   ```

2. Откройте Chrome и перейдите в `chrome://extensions/`

3. Включите **Режим разработчика** (переключатель в правом верхнем углу)

4. Нажмите **Загрузить распакованное расширение**

5. Выберите папку `fractal-reader`

## Настройка

1. Кликните на иконку расширения в панели Chrome
2. Введите ваш Anthropic API ключ
3. Получить ключ можно на [console.anthropic.com](https://console.anthropic.com/)

## Использование

1. Выделите любой текст на веб-странице
2. Появится кнопка **Analyze**
3. Нажмите на неё и дождитесь анализа
4. Переключайтесь между вкладками для разных типов анализа
